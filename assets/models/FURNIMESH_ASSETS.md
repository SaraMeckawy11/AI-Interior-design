# FurniMesh assets

These models are embedded in Livinai's furnished 3D plan experience.

| Local file | Model | Source |
| --- | --- | --- |
| `furnimesh-dining-rectangular.glb` | Sculptural Dark Wood Dining Table | https://furnimesh.com/library/tables/dining-table/a-contemporary-dining-table-featuring-a-rectangular-wjo8lo/ |
| `furnimesh-dining-round-modern.glb` | Geometric Black Wood Dining Table | https://furnimesh.com/library/tables/dining-table/a-round-dining-table-with-a-dark-pqzubn/ |

The matching `*-native.glb` files are geometry-optimized copies used by the
native walkthrough exporter. They preserve the downloaded silhouettes while
keeping scene generation responsive; the browser preview uses the full models.

FurniMesh states that models in its public library are free for commercial use
without attribution. The public library and terms should be reviewed again before
redistributing these files outside the Livinai application.

- Library license statement: https://furnimesh.com/library/
- Terms: https://furnimesh.com/terms/
